# Browser evidence

Generated by `cd web && npm run build && E2E_PRODUCTION=true npm run e2e`.

`desktop-*` uses a 1440px viewport. `mobile-*` uses 320px. Files cover initial state, four verdicts, full free plan, dated-plan fallback, discovery, three-trail comparison, bounded Ask and workspace states.

Workspace progress uses a stubbed account transport, not a real Supabase account. Other screenshots use the compiled catalog and real local Python service. Dates are generated relative to the test date. See [verification boundaries](../verification.md).
